* Snowflake is saas appication .
* While it got setup , you can chose on which cloud you can host your Snowflake platform 
    * You can choose the cloud and region and it helps to setup the snowflake in the region where your customers are available 
* Snowflake Editions depends on features & pricing :
    * Standard 
    * ENterprize 
    * Businesss critical 
    * VPS - Isolated snowflake environment 

* Default Roles :
    * account Admin - Create DBs, create users ...
    * Security Admin 
    * System admin 
    * Public 
    * Org Admin 
    * Customer roles 

* Snowflake Architecture :
    * Cloud service layer  - security , Management , Metadata , optimization
    * Compute - Virtual Warehouses 
    * Database storage layer  - Structured , semistructured , unstructured


* Virtual warehouse depends on type , size , scaling & automation:
    * standard - cpu capabilities 
    * Snowpark-optimised - memory capabilities 
    * Adaptive - latest , snowflake takes care of call on cpu/memory is needed 
* Clusters : It is the scaling of Virtual warehouses
    * Single cluster with autoscale mode 

* Pricing depends up on the region and the edition of snowflake(standard/Enterprize) you have  choosen 
    * Find the regions and cloud providers here : https://status.snowflake.com/

* Create a worksheet :
    * Workspace >> Add new >> Create a a sql editor 
* While working on worksheet, take a look at role/warehouse/DB/SCHEMA that is on the right top of your worksheet 
* Each databse created in Snowflake will have below :
    * Public schema 
    * Information schema 
    * Your schema 
* Different tables in schema :
    * Permanent - Timetravel,  Fail-safe
    * Temporary - Timetravel,  No Fail-Safe
    * Transient - Timetravel,  No Fail-Safe
    * External  - No TimeTravel , No Fail-Safe

* Schema objects :
    * Tables 
    * Views - Join tables and create a view , logical representation of tables 
        * Standard 
        * Secure 
        * Materialized
    * Stages - Unstructured data like files and folders upload - connected to other providers and get data based on schedule/batch
